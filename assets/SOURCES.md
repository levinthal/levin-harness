# Homepage visual sources

The homepage combines capability diagrams with actual application captures. It does not report a completed binder-design campaign.

| Asset | Origin and scope |
| --- | --- |
| `wordmark-color-on-light.png` / `wordmark-color-on-dark.png` | The official transparent application mark from `pics/app.icon.windows.png`, retaining its blue-purple-to-magenta gradient, composed with the website's ZCode wordmark. Both variants use the same colored mark; the text adapts to the page theme. |
| `system-overview*.png` / `.svg` | Authored capability diagrams in the Lévin palette. The SVGs are editable originals; the PNGs are rendered exports. Binder design illustrates relationships between product capabilities. No scientific result is depicted. |
| `plugin-ecosystem-native.webp` | Captured with macOS system window capture from the installed Lévin™ Harness 2.1107.0 application on November 8, 2026, using a separate local capture profile. Shows the real bundled catalog. No deployment or computation was submitted. |
| `workflow-example-template-native.webp` | System window capture of the same application's real Workflow editor. The saved source is [binder-design-review.workflow.json](../examples/binder-design-review.workflow.json). It is a documentation example, not an executed or validated campaign. |
| `knowledge-collections-native.webp` | System window capture of the same application's real Knowledge page. Reference notes were prepared from [the public plugin documentation](https://levinthal.design/plugins.html) and actually collected into the capture profile. No scientific findings or research history were invented. |
| `molecular-workspace-purple-native.webp` | System window capture of a real English-language session in Lévin™ Harness 2.1107.0 on November 8, 2026, using the separate capture profile. The agent loaded public PDB structure 4HHB, applied a coordinated purple custom chain palette, and configured cartoon ribbons with a translucent Gaussian surface. The conversation is actual model output. No prediction or binder-design experiment was performed. Used on both homepages. |

System window captures preserve the native macOS composition, including vibrancy. Only rounded outer-corner transparency is flattened against the app background before resizing and WebP encoding. All published application screenshots are opaque RGB images so the hosting page cannot change their appearance. Interface text, structures, states and results were not repainted or reconstructed. Screenshots may show a newer local preview than the currently published installer.

The remaining images are earlier product assets retained for repository history. The homepage uses the files listed above.
