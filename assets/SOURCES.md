# Homepage visual sources

The homepage combines capability diagrams with actual application captures. It does not report a completed binder-design campaign.

| Asset | Origin and scope |
| --- | --- |
| `system-overview*.png` / `.svg` | Authored capability diagrams in the Lévin palette. The SVGs are editable originals; the PNGs are rendered exports. Binder design illustrates relationships between product capabilities. No scientific result is depicted. |
| `plugin-ecosystem.webp` | Captured from the installed Lévin™ Harness 2.1107.0 application on November 8, 2026, using a separate local capture profile. Shows the real bundled catalog. No deployment or computation was submitted. |
| `workflow-example-template.webp` | Captured from the same application's real Workflow editor. The saved source is [binder-design-review.workflow.json](../examples/binder-design-review.workflow.json). It is a documentation example, not an executed or validated campaign. |
| `knowledge-collections.webp` | Captured from the same application's real Knowledge page. Reference notes were prepared from [the public plugin documentation](https://levinthal.design/plugins.html) and actually collected into the capture profile. No scientific findings or research history were invented. |
| `molecular-workspace-current.webp` | An actual existing molecular visualization session captured on October 30, 2026. Shows a `sample` / `pred` structure comparison and representation adjustments. It is an interface example, not evidence of binder performance. |

Application captures were resized and encoded as WebP for the README. Interface text, structures, states and results were not repainted or composited. Screenshots may show a newer local preview than the currently published installer.

The remaining images are earlier product assets retained for repository history. The homepage uses the files listed above and the existing light/dark wordmarks.
